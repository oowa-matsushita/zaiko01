作成：2026-11-12。個人アカウントの Claude から会社アカウントの Claude へ引き継ぐためのもの。
利用者は中古車の買取・オークション出品をしている会社の担当者。エンジニアではない。

## 1. このサイトの目的
中古車の買取在庫を管理する社内用サイト。主に PC（縦型モニター）とスマホで使う。
- 在庫の登録・一覧・直接編集、オークション（AA）の開催日・出庫日の管理、陸送会社の手配
- 在庫CSV・AA結果CSV（社内システムから出力、Shift-JIS）の取り込み
- 出品依頼文（LINE・メールに貼る）や一覧の印刷
- 過去のAA結果から相場を表示

## 3. 画面と機能（現在の仕様）
**タブ**：在庫一覧／AA結果／データをアップロード

**在庫一覧（index.html）**
- 表は1段表示のみ。列：No.・初度登録・車名・グレード・車台番号・色・カラーコード・走行距離・買取金額・着地予想・予定価格・自社名・会場・開催日・出庫日・陸送会社・メモ・登録日
- No.・初度登録・車名は横スクロールで左に固定。クリックした行は黄色。セルはダブルクリック（スマホはダブルタップ）で直接編集
- 表の高さは画面の約2/3で縦スクロール。はみ出す場合は文字を自動で縮小（1rem〜0.78rem）
- 初度登録は「H24/6」「R3/11」の短縮表示（保存は「平成24年06月」のまま）
- 色は「白（ホワイト）」形式に統一表示（保存は元の色名）。アイボリーはそのまま
- 自社名は「日付」（名前ではない）。開催日・出庫日はカレンダー入力
- 会場：名古屋（金曜開催・緑）、静岡（土曜開催・橙）、廃車。曜日が合わない開催日は赤で警告
- 陸送会社：シンセイ①〜④・タカラ・自社（旧「シンセイ」「シンセイ1〜4」は自動変換・保存可）
- 予定価格は税抜で保存、表示・入力は税込（×1.1）
- 上部：検索欄（全角も可、件数表示、クリア）／開催日・出庫日のカレンダー（同じ日付を上下にそろえ横スクロール。開催日は4週間の金土、出庫日は7日分＋それ以降で予定のある日。出庫日の枠内に陸送会社別ボタン）
- ボタン：出庫前のみ表示（既定オン、出庫日が今日以降または未定）／自社名済のみ表示／自社名待ちのみ表示／陸送会社の絞り込み／一覧印刷（A4横）／依頼する（メール文・PDF）
- 依頼メール：開催日・会場・出庫日が同じ車両をまとめて見出しに書き、各車両は「車名　車台番号下4桁　色」
- 車名の横の紫「相場n」：マウスオーバー（スマホはタップ）で相場（この車両自身の過去の出品、型式が同じで年式・走行が近い車両、落札の中央値・平均・幅）
- 買取登録フォーム：コーションプレート撮影で車台番号・カラーコードを Workers AI で読み取り（**本番での動作は未確認**）
- ボタンは角が四角。背景は白

**AA結果（aa.html）**：取り込んだオークション結果の一覧。検索・開催日・結果で絞り込み、件数と落札平均、在庫にある車両は黄色

**データをアップロード（upload.html）**
- 在庫CSV（列名で判別：愛称名→車名、色→色とカラーコード、初度→初度登録、仕入金額→買取金額、予定売価本体予定→予定価格、グレード）
  - 車台番号が同じ車両は上書きしない。ただし「予定価格」「グレード」はCSVの値で上書き（チェックで切替、既定オン）。「空欄だけ補う」も選択可
  - 予定売価の 7,070,706 / 46,909,091 は利用者の指示で除外せず取り込む
- AA結果CSV（「セリ結果」「応札額」列で自動判別）。開催日・会場・出品番号で重複スキップ。応札額は千円単位として表示
- バックアップ（全データ JSON ダウンロード）と復元（空のサイトにだけ）
- 最終取り込み日時を記録し、一覧の「データをアップロード」の下に表示

**ログイン**：ID・パスワード（6文字以上）。失敗が続くとロック（同じIPから15分に5回、全体で15分に10回）。Cloudflare Access のメール認証は使っていない

## 4. 利用者が外した・やめたもの（データは残している）
保証書・取説・セールスポイント（音声入力ボタンも）・価格/ステータス/集計の旧画面・CSV出力・2段表示と表示切替・自社名（文字）

## 4.5 相場データ（2026-11-14 変更）
- 相場は AA結果CSV ではなく、社内システムの**契約書データ**（オークション会社への販売分）を使う。変換ルールは CLAUDE.md
- Claude が `API_TOKEN` で相場データを直接入れ替えられるようにした（`scripts/market-upload.mjs`）
- 相場の吹き出しは画面内に収まるよう配置を調整、スマホは1台ずつ折り返し表示

## 5. 提案したがまだ作っていないもの
- **LINEの文面から開催日を反映**：例「(2145859) ヴィッツ (0000366) シフォン ですが、11月13日出品で…」→ かっこ内の番号を車台番号の末尾と照合して開催日を更新。
  A案（文面を貼り付けて確認後に反映）を推奨。B案（LINE公式アカウントのボットで自動。受信は無料、送信は月200通まで無料）は利用者が費用を確認した段階で止まっている。会場の決め方（送り主など）は未回答
- Claude からデータを操作する MCP 連携（最初に提案、未着手）
- 毎日の自動バックアップ（R2）
- AA結果タブへの中央値表示
